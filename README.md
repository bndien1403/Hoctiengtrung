# Hán Ngữ Cùng Nhau

Trang học tiếng Trung cho nhóm 5 người: lộ trình Pinyin → HSK 6, chữ Hán, luyện nghe nói, ôn tập lặp lại ngắt quãng, trợ lý AI **Như Yên** (trò chuyện và gọi thoại), đấu trường và bảng xếp hạng.

- Chạy trên GitHub Pages, dữ liệu nhóm trên Firebase, AI dùng Gemini.
- Hướng dẫn cài đặt cho chủ nhóm: mở `setup.html` trên trang web.
- Cấu hình Firebase nằm trong `config.js`.
