Cài đặt trang học cho nhóm

Dành cho chủ nhóm. Làm một lần, khoảng 10–15 phút trên điện thoại. Tất cả đều miễn phí, không cần thẻ ngân hàng.

1Tạo dự án Firebase

  1. Mở console.firebase.google.com, đăng nhập bằng Gmail.
  2. Chạm Tạo dự án (Create a project), đặt tên ví dụ hanngu. Tắt Google Analytics rồi tạo dự án.
  3. Ở menu bên trái chọn Bảo mật / Security → Authentication (có giao diện ghi là Build → Authentication) → Bắt đầu → thẻ Phương thức đăng nhập → Email/Mật khẩu → bật dòng đầu tiên → Lưu.
  4. Chọn Firestore Database → Tạo cơ sở dữ liệu → vị trí asia-southeast1 (Singapore) → chọn chế độ sản xuất (production) → Tạo.

2Dán luật bảo mật

Trong Firestore, mở thẻ Quy tắc / Rules, xoá hết nội dung cũ, dán đoạn dưới đây rồi chạm Xuất bản / Publish. Luật này chỉ cho thành viên có mã mời vào nhóm, tối đa 5 người.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function signedIn() { return request.auth != null; }
    function uid() { return request.auth.uid; }
    function isMember() { return signedIn() && exists(/databases/$(database)/documents/accounts/$(request.auth.uid)); }
    function isOwner() { return signedIn() && get(/databases/$(database)/documents/config/secret).data.owner == request.auth.uid; }
    function isMe(u) { return signedIn() && request.auth.uid == u; }

    // Public group info: member count, group name
    match /config/public {
      allow read: if true;
      allow create: if signedIn()
        && request.resource.data.owner == uid()
        && request.resource.data.members == 1
        && getAfter(/databases/$(database)/documents/config/secret).data.owner == uid();
      allow update: if isOwner()
        || (signedIn()
            && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['members'])
            && request.resource.data.members == resource.data.members + 1
            && request.resource.data.members <= resource.data.max
            && !exists(/databases/$(database)/documents/accounts/$(request.auth.uid))
            && existsAfter(/databases/$(database)/documents/accounts/$(request.auth.uid)));
    }

    // Invite code and Gemini key: members read, owner writes
    match /config/secret {
      allow read: if isMember();
      allow create: if signedIn()
        && request.resource.data.owner == uid()
        && !exists(/databases/$(database)/documents/config/public);
      allow update: if isOwner() && request.resource.data.owner == resource.data.owner;
    }

    // Accounts: created with the right invite code (or by the group creator)
    match /accounts/{u} {
      allow read: if isMember();
      allow create: if isMe(u)
        && request.resource.data.invite == getAfter(/databases/$(database)/documents/config/secret).data.invite
        && ((exists(/databases/$(database)/documents/config/public)
             && getAfter(/databases/$(database)/documents/config/public).data.members
                == get(/databases/$(database)/documents/config/public).data.members + 1)
          || (!exists(/databases/$(database)/documents/config/public)
             && getAfter(/databases/$(database)/documents/config/public).data.members == 1));
      allow update: if isMe(u) && request.resource.data.invite == resource.data.invite;
      allow delete: if isOwner();
    }

    match /progress/{u} { allow read, write: if isMe(u) && isMember(); }
    match /srs/{u} { allow read, write: if isMe(u) && isMember(); }
    match /players/{u} {
      allow read: if isMember();
      allow write: if isMe(u) && isMember();
      allow delete: if isOwner();
    }
    match /presence/{u} {
      allow read: if isMember();
      allow write: if isMe(u) && isMember();
      allow delete: if isOwner();
    }
    match /msgs/{id} {
      allow read: if isMember();
      allow create: if isMember() && request.resource.data.u == uid() && request.resource.data.t is string && request.resource.data.t.size() <= 500;
      allow delete: if isMember();
    }
    match /meet/{id} { allow read, write: if isMember(); }
    match /arena/{id} { allow read, write: if isMember(); }
    match /vocabai/{id} { allow read, write: if isMember(); }
    match /matches/{m}/r/{u} {
      allow read: if isMember();
      allow write: if isMe(u) && isMember();
    }
  }
}

3Lấy cấu hình web

  1. Chạm biểu tượng bánh răng → Cài đặt dự án (Project settings).
  2. Kéo xuống mục Ứng dụng của bạn → chạm biểu tượng </> (Web) → đặt tên web → Đăng ký ứng dụng (không cần chọn Hosting).
  3. Sao chép đoạn const firebaseConfig = { … } và gửi cho Claude trong cuộc trò chuyện. Các giá trị này là định danh công khai của dự án, gửi đi không sao.

4Lập nhóm và nhập khoá AI

  1. Khi trang đã có cấu hình, mở trang học và chọn Lập nhóm mới. Người đầu tiên là chủ nhóm và nhận mã mời.
  2. Mở aistudio.google.com/apikey → Create API key → sao chép khoá (bắt đầu bằng AIza).
  3. Trong trang học, chạm ảnh đại diện góc trên → Quản lý nhóm → dán khoá Gemini → Lưu khoá. Như Yên sẽ trò chuyện và gọi thoại được.
  4. Gửi đường liên kết trang học và mã mời cho 4 người còn lại. Mỗi người chọn Tạo tài khoản và nhập mã mời.

5Cài lên màn hình điện thoại

Android (Chrome): mở trang → menu ⋮ → Thêm vào màn hình chính / Cài đặt ứng dụng.
iPhone (Safari): nút Chia sẻ → Thêm vào MH chính.
Trang sẽ mở như một ứng dụng riêng, có biểu tượng chữ 汉.

Quên mật khẩu? Chủ nhóm vào Cài đặt → Quản lý thành viên → Xoá tài khoản đó, bấm “Đổi mã mời”, rồi người kia đăng ký lại bằng tên đăng nhập mới. Tài khoản cũ có thể xoá hẳn trong Firebase → Authentication → Users.
